# Formulário de Cadastro — Metaverso X

Formulário de cadastro responsivo com validação em tempo real, feito com HTML, CSS e JavaScript puro.

## Funcionalidades

- Layout em duas colunas no desktop e uma coluna no celular
- Validação de todos os campos com mensagens em português:
  - nome e sobrenome obrigatórios
  - e-mail em formato válido
  - celular com DDD e máscara automática `(81) 98552-1475`
  - senha com no mínimo 8 caracteres, letras e números
  - confirmação de senha igual à senha
- Mensagem de sucesso ao enviar
- Acessível: `label` em todos os campos, `fieldset`/`legend` no gênero, erros anunciados por leitores de tela

## Rodando

Abra `Formulario-MetaX/index.html` no navegador.

> Projeto de front-end: os dados não são enviados para nenhum servidor.
